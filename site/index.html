LA CRAIA

Decentralized Automotive Audio Suite • Paredão & Simbiótyka HUD

Streaming contínuo guiado por grafos de similaridade acústica, rádio sem algoritmo corporativo e projeção tátil de letras em tempo real sincronizadas diretamente sobre a navegação GPS (Waze).

Metameria do Sistema

[ METÂMERO 01: COMPARTILHADO ]

lacraia-shared

Modelos de domínio, parser de letras LRC em centissegundos, higienizador acústico de duração/título e protocolo WebSocket de telemetria.

[ METÂMERO 02: ORQUESTRADOR ]

lacraia-core

Servidor Baquara (Debian 13). Grafo de afinidade em SQLite, extrator yt-dlp/ffmpeg, cache estático em Opus com HTTP Range e daemon antecipado de 2 faixas.

[ METÂMERO 03: COCKPIT PLAYER ]

lacraia-app

Player nativo Linux Desktop e PWA em Dioxus. Seletor de estações, controle de fila e integração MediaSession com hardware automotivo.

[ METÂMERO 04: O COMPANHEIRO ]

La Craia Simbiótyka

Micro-app Android (Kotlin Foreground Service). Intercepta sessões de mídia, sincroniza letras via LRCLIB e projeta overlay pill flutuante com ducking de áudio para avisos do Waze.

Comunicações de Bordo

📡 [ TRANSMISSÃO DE CABINE ]
A telemetria do sistema opera em 1Hz transmitindo instantaneamente a posição da agulha para o HUD e o cockpit player simultaneamente via WebSocket.
⚡ [ FIO DESENCAPADO ]
Ao passar por zonas sem cobertura celular, o sistema entra em modo 100% offline, operando pelo grafo local de faixas pré-resolvidas em cache.
🦂 [ VENENO NA CARNE ]
Filtro de ruído acústico ativado: faixas com variação de tempo maior que 15 segundos ou títulos identificados como covers e tributes não autorizados são sumariamente expurgados da fila.
✨ [ O PULO DA TRAVESTI ]
Para iniciar imediatamente toda a bancada de testes e o backend pré-populado com sementes de demonstração, basta disparar o script de orquestração única.

Bancada de Acionamento

Comandos para disparo da demonstração e verificação do ecossistema:

[ TERMINAL :: DISPARAR DEMO COMPLETA ] 
# Clonar e iniciar o backend com seeding automático e painel no navegador:
git clone ssh://git@codeberg.org/lumenpink/lacraia.git
cd lacraia
./demo.sh --port 8080 --open
[ TERMINAL :: COMPILAÇÃO LINUX DESKTOP NATIVO ] 
# Executar o player Dioxus compilado como binário nativo no desktop Linux:
